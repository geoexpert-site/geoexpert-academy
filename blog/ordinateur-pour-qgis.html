QGIS : quel ordinateur faut-il vraiment ?

1 novembre 2026 5 min de lecture GeoExpert Academy & Consulting

Pour débuter avec QGIS, la configuration que nous conseillons pour nos formations est un ordinateur sous Windows 10 ou 11 avec 8 Go de mémoire vive. QGIS est gratuit et réputé fonctionner sur des ordinateurs peu puissants : ce sont surtout la taille de vos données et votre confort de travail qui demandent plus. Un téléphone permet de regarder les vidéos, mais pas de pratiquer.

Quelle configuration est conseillée pour débuter avec QGIS ?

Pour suivre nos formations, nous conseillons :

  • Windows 10 ou 11 ;
  • 8 Go de mémoire vive (RAM) ;
  • de l'espace libre sur le disque pour les données des exercices.

C'est une configuration conseillée, pas un minimum officiel. Les exigences techniques exactes de chaque version de QGIS sont publiées dans la documentation du logiciel : consultez-la avant d'acheter ou de remplacer un ordinateur.

QGIS existe aussi pour Mac et Linux, comme nous l'expliquons dans notre comparatif QGIS vs ArcGIS. Notre configuration conseillée reste Windows 10 ou 11.

Pourquoi 8 Go de mémoire vive ?

Pendant une séance, votre ordinateur fait fonctionner en même temps Windows, QGIS, un navigateur pour la vidéo de la leçon et parfois d'autres programmes. À cela s'ajoutent les couches de données que vous ouvrez dans votre projet. Avec 8 Go, vous avez de la marge pour que tout cela cohabite correctement.

Avec moins de mémoire, l'ordinateur pourrait ralentir dès que vous ouvrez plusieurs couches volumineuses ou que vous gardez beaucoup de programmes ouverts. Nous ne pouvons pas le garantir dans tous les cas : cela dépend de l'ordinateur et des données.

Un téléphone ou une tablette peuvent-ils suffire ?

Pour regarder les vidéos, oui : un téléphone suffit. Pour refaire les manipulations, non : il faut un ordinateur. Or c'est la pratique qui vous fait progresser. Si vous n'avez pas d'ordinateur personnel, réfléchissez à l'endroit et aux horaires où vous pourrez en utiliser un régulièrement avant de vous inscrire.

Et pour ArcGIS ?

ArcGIS est un logiciel payant : il demande une licence, souvent fournie par l'employeur ou l'école. Sur notre plateforme, les formations ArcGIS utilisent ArcMap, qui fonctionne uniquement sous Windows. Notre comparatif indique par ailleurs qu'ArcGIS est en général plus exigeant que QGIS sur la puissance de l'ordinateur. Dans les deux cas, la configuration conseillée ci-dessus est un bon point de départ.

Ordinateur portable ou ordinateur fixe ?

Pour apprendre, les deux conviennent, à condition de respecter la configuration conseillée. Un portable se déplace et fonctionne sur batterie : si l'alimentation électrique est irrégulière là où vous travaillez, cela peut vous éviter de perdre une séance. Un ordinateur fixe, lui, offre souvent un écran plus grand, ce qui est agréable pour garder la vidéo d'un côté et QGIS de l'autre. Un écran plus grand est un confort, pas une obligation. Une souris est utile pour manipuler précisément la carte, même si vous pouvez vous en passer.

Que faire si votre ordinateur est ancien ou limité ?

  • Fermez les programmes inutiles pendant que vous travaillez dans QGIS.
  • Travaillez sur de petits jeux de données pendant l'apprentissage : les exercices d'initiation n'ont pas besoin de données volumineuses.
  • Gardez de l'espace libre sur le disque et supprimez les fichiers dont vous n'avez plus besoin.
  • Sauvegardez régulièrement votre projet, surtout si votre ordinateur se bloque parfois.
  • Posez la question avant de commander. Si vous hésitez sur votre configuration, écrivez-nous sur WhatsApp : nous vous confirmons si votre ordinateur convient.

Comment vérifier la mémoire vive de votre ordinateur ?

Sous Windows, ouvrez les paramètres, rubrique « Système », puis la section « À propos de ». Vous y trouverez la mémoire vive installée (« RAM installée ») et la version de Windows. Comparez ces informations avec la configuration conseillée ci-dessus.

Comment tester avant de vous engager ?

Le plus simple est d'installer QGIS, qui est gratuit, et d'ouvrir un petit projet pour voir si l'ordinateur reste fluide. Si vous passez ensuite par l'une de nos formations, la période d'essai de 7 jours, accompagnée sur WhatsApp, vous permet de vérifier que tout fonctionne avant d'aller plus loin. Pour la méthode générale, voir Apprendre le SIG en ligne : est-ce possible ?

Questions fréquentes

Quelle est la configuration conseillée pour QGIS ?

Pour nos formations, nous conseillons Windows 10 ou 11, 8 Go de mémoire vive et de l'espace libre pour les données. C'est une configuration conseillée, pas un minimum officiel de QGIS.

Peut-on utiliser QGIS avec 4 Go de mémoire vive ?

Nous ne le conseillons pas pour suivre nos formations, car nous recommandons 8 Go. Avec 4 Go, cela pourrait fonctionner sur de petits jeux de données, mais nous ne pouvons pas le garantir. En cas de doute, écrivez-nous sur WhatsApp.

QGIS fonctionne-t-il sur Mac et sur Linux ?

Oui, QGIS est téléchargeable sur Windows, Mac et Linux. La configuration que nous conseillons pour nos formations reste Windows 10 ou 11.

Faut-il une carte graphique particulière ?

La configuration que nous conseillons ne fixe pas de carte graphique particulière. Si vous avez un doute sur votre ordinateur, écrivez-nous sur WhatsApp avant de commander.

Un téléphone suffit-il pour apprendre QGIS ?

Un téléphone suffit pour regarder les vidéos, mais il faut un ordinateur pour refaire les manipulations dans QGIS.
