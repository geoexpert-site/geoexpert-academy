Introduction à Google Earth Engine pour débutants

7 octobre 2026 7 min de lecture Jean Eudes AKA

Google Earth Engine (GEE) révolutionne la télédétection. Cette plateforme gratuite de Google permet d'analyser des décennies d'images satellitaires en quelques clics, sans installer de logiciel ni télécharger des téraoctets de données.

Qu'est-ce que Google Earth Engine ?

Google Earth Engine est une plateforme cloud gratuite développée par Google pour l'analyse de données géospatiales à grande échelle.

Elle donne accès à :

  • Une archive de 40+ ans d'images satellitaires (Landsat, Sentinel, MODIS...)
  • Des données climatiques, d'élévation, d'occupation du sol
  • Une puissance de calcul colossale (les serveurs de Google)
  • Un éditeur de code en ligne (JavaScript)

En résumé : vous pouvez analyser des milliers d'images satellite en quelques minutes, ce qui prendrait des jours sur un ordinateur classique.

Pourquoi c'est une révolution

Avant Google Earth Engine

  • Télécharger des téraoctets d'images satellite
  • Avoir un ordinateur très puissant (32+ Go de RAM)
  • Passer des heures, voire des jours, à traiter les données
  • Gérer un espace de stockage énorme

Avec Google Earth Engine

  • Tout est déjà sur les serveurs de Google
  • Un simple ordinateur portable suffit
  • Les calculs se font en quelques secondes
  • Aucun stockage local nécessaire

Que peut-on faire avec GEE ?

  • Suivre la déforestation année par année
  • Détecter les feux de forêt en temps réel
  • Cartographier l'occupation du sol (agriculture, urbain, forêt)
  • Calculer des indices de végétation (NDVI) sur 20 ans
  • Suivre l'expansion urbaine des villes
  • Analyser les sécheresses et les inondations
  • Cartographier les zones humides
  • Prédire les rendements agricoles

Comment démarrer ?

Étape 1 : Créer un compte

Rendez-vous sur earthengine.google.com et inscrivez-vous avec un compte Google. L'inscription est gratuite pour les usages académiques, la recherche et les projets à but non lucratif.

L'approbation prend généralement quelques jours. Il faut expliquer votre projet dans le formulaire d'inscription.

Étape 2 : Découvrir le Code Editor

Une fois votre compte validé, vous accédez au Code Editor, l'interface principale de GEE. Elle comprend :

  • Une zone de code JavaScript
  • Une carte Google Maps interactive
  • Une console de résultats
  • Un explorateur de données (le catalogue)

Étape 3 : Premier script simple

Voici un script GEE simple qui affiche une image satellite :

  • Charger une image Sentinel-2 : grâce à la fonction ee.Image()
  • Sélectionner les bandes (rouge, vert, bleu)
  • Ajouter l'image à la carte : avec Map.addLayer()

En quelques lignes, vous affichez une image satellite de la zone de votre choix.

Étape 4 : Explorer les exemples

GEE propose une bibliothèque d'exemples commentés. C'est la meilleure façon d'apprendre :

  • Calculer le NDVI d'une zone
  • Détecter les changements d'occupation du sol
  • Créer une série temporelle d'images
  • Exporter les résultats vers QGIS

GEE vs QGIS : sont-ils concurrents ?

Non, ils sont complémentaires.

  • QGIS : idéal pour les analyses locales, la cartographie, les petits projets
  • GEE : idéal pour les analyses à grande échelle, les séries temporelles, le traitement d'énormes volumes de données

Le workflow idéal : vous préparez et analysez de grandes quantités d'images satellite dans GEE, puis vous exportez les résultats vers QGIS pour la cartographie finale.

Faut-il savoir coder pour utiliser GEE ?

GEE utilise JavaScript. Rassurez-vous :

  • Les bases suffisent pour 80% des cas d'usage
  • Des centaines d'exemples sont disponibles à copier-coller
  • La documentation est très bien faite
  • La communauté est active et réactive

Si vous débutez, vous pouvez commencer sans rien connaître au code : copiez les exemples, modifiez-les légèrement, observez les résultats. La programmation viendra naturellement avec la pratique.

Les limites de GEE

GEE n'est pas parfait. Voici ses limites :

  • Nécessite une connexion Internet stable
  • Approbation du compte longue (parfois plusieurs semaines)
  • Export de données limité en taille
  • JavaScript à apprendre pour aller loin
  • Interface peu intuitive au début

Malgré ces limites, GEE reste l'outil le plus puissant disponible gratuitement pour la télédétection.

Conclusion

Google Earth Engine est en train de changer le métier de géomaticien. Ce qui prenait des semaines se fait maintenant en quelques heures. Les professionnels qui maîtrisent GEE ont un vrai avantage sur le marché du travail.

Pour débuter : créez un compte, testez les exemples officiels, modifiez-les, explorez. La courbe d'apprentissage est raide au début, mais les possibilités sont immenses.
